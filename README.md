# Student Performance Analyzer & Score Predictor

A beginner-friendly data analysis and machine learning project built with **Python, Pandas and NumPy**.
It cleans a messy student dataset, analyses what affects exam scores, and predicts a student's final score
using a **linear regression model written from scratch with NumPy** (no scikit-learn).

> Note: the dataset is synthetic (generated by `generate_data.py`) so the project runs anywhere.
> You can replace `data/students.csv` with real data that has the same columns.

## What it does
1. **Data cleaning (Pandas):** removes duplicate students, fixes invalid attendance (>100%), fills missing values with the median
2. **Feature engineering:** attendance bands, grades (F to A+), pass/fail result
3. **Analysis:** summary statistics, correlation of each factor with final score, average score by attendance band, grade distribution
4. **ML model (NumPy):** linear regression with feature scaling, least-squares solving, train/test split, and MAE / RMSE / R2 evaluation
5. **Prediction:** predict a score from the command line
6. **Outputs:** `output/report.txt` and `output/cleaned_students.csv`

## How to run
```bash
pip install -r requirements.txt
python generate_data.py          # creates data/students.csv
python main.py                   # runs the full pipeline and saves the report
python main.py --predict 6 90 70 7   # study_hours attendance prev_score sleep_hours
```

## Sample results
- 305 raw rows -> 300 clean rows (5 duplicates removed, 22 missing/invalid values fixed)
- Study hours had the strongest correlation with final score (about 0.83)
- Model performance on unseen test data: R2 about 0.83, MAE about 3.6 marks

## Tech stack
Python, Pandas, NumPy
